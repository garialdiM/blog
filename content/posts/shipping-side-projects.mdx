Everyone has a graveyard of half-finished side projects. The problem is rarely a lack of skill — it's a lack of constraints. Here's how I started actually shipping.

## Cut the scope in half. Then again.

Your first version should feel almost embarrassingly small. If you can describe it in one sentence without using the word "and," you're close.

```ts
// The whole MVP, conceptually
type MVP = {
  oneCoreFeature: true
  everythingElse: "later"
}
```

## Set a deadline you'll respect

A project without a deadline expands forever. Give yourself a weekend, or two weeks max for the first release. Constraints force decisions.

## Ship before you're ready

You will never feel ready. Publish the rough version, get it in front of real people, and let their feedback guide what comes next.

> A shipped project that's imperfect beats a perfect project that never leaves your laptop.

Finish small, ship often, iterate in public. That loop compounds faster than any grand plan.
